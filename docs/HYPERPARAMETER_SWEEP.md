# Hyperparameter Sweep

`scripts/run_hyperparameter_sweep.py` runs the greedy solver across a fixed grid of
beam widths, lookahead depths, and top-k failure penalty values inside the same
Ubuntu 22.04 Docker envelope used by the grading smoke test.

Run it from the repository root:

```bash
python3 scripts/run_hyperparameter_sweep.py
```

The default command:

- builds `run_solver` and `evaluate_debug` in `build-ubuntu22-sweep`
- reads benchmark inputs from `benchmarks/mlsys-2026-*.json`
- records beam width `32`, lookahead depth `0`, and alpha `0.04` as the
  default greedy configuration; alpha `0.16` is an alternate tuned value with
  equivalent sweep results
- writes per-run solutions and logs under
  `build-ubuntu22-sweep/hyperparameter-sweeps/<timestamp>`
- updates JSON, CSV, and XLSX result summaries after every benchmark run

## Requirements

- Docker
- Python 3
- the benchmark JSON files in `benchmarks/`
- Matplotlib, only for `scripts/plot_hyperparameter_sweep.py`

## Common Commands

Run the full sweep:

```bash
python3 scripts/run_hyperparameter_sweep.py
```

Reuse an existing Docker build directory:

```bash
python3 scripts/run_hyperparameter_sweep.py --skip-build
```

Stop after the first solver failure:

```bash
python3 scripts/run_hyperparameter_sweep.py --stop-on-failure
```

Rank completed configurations:

```bash
python3 scripts/rank_hyperparameter_sweep.py \
  build-ubuntu22-sweep/hyperparameter-sweeps/<timestamp>
```

Plot latency speedup:

```bash
python3 scripts/plot_hyperparameter_sweep.py \
  build-ubuntu22-sweep/hyperparameter-sweeps/<timestamp>
```

If no sweep path is provided, the rank and plot scripts use the newest local
`hyperparameter_sweep_index.json` under
`build-ubuntu22-sweep/hyperparameter-sweeps`.

## Outputs

Each sweep directory contains:

- `hyperparameter_sweep_index.json`: machine-readable run metadata, defaults, grid, and rows
- `hyperparameter_sweep_results.csv`: tabular result rows
- `hyperparameter_sweep_results.xlsx`: spreadsheet-friendly result rows
- `solutions/`: generated solution JSON files, grouped by configuration
- `logs/`: captured solver stdout and stderr, grouped by configuration
- `plots/latency_speedup.png`: generated by `plot_hyperparameter_sweep.py`

The plot compares each configuration against the default greedy configuration
recorded in the sweep index.
